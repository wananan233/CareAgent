# G0 威胁模型

| 威胁 | 边界 | G0 控制措施 |
|---|---|---|
| 提示注入 | 语音、家属消息、文件均为不可信输入 | 模型仅允许固定 Schema 输出；不暴露内部 URL、凭证、数据库结构或设备命令。 |
| 越权执行 | Agent/模型尝试调用高副作用能力 | 默认拒绝的能力矩阵；模型无 Skill 权限；`create_alert` 仅 Rule Engine 可用。 |
| 用药事实夸大 | 开仓/重量被写作已吞服 | 契约仅传递 evidence；`UNKNOWN` 为合法结果，禁止 `mark_medication_taken`。 |
| 重放/重复副作用 | 网络重试或进程恢复 | ActionIntent 强制 idempotency_key；后续 G1 以 Event Store 与 Outbox 落地。 |
| 隐私泄露 | 原始音视频或完整健康文本进入日志/云端 | G0 fixture 仅使用合成数据；默认不定义原始音视频字段；日志只保留伪匿名 ID 与错误码。 |
| 跨用户读取 | 错误的 subject/household 绑定 | 每个授权决策要求 subject、household、purpose、consent、expiry。 |
