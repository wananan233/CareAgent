# I0 集成闭环阶段基线

## 阶段入口

- 阶段：I0 双端与 Core/CareAgent 集成闭环。
- 基线提交：`fbea952`（V0 Linux 视觉验收完成）。
- 范围：统一启动、GSC-01–07 场景 replay、角色化一致、授权传播、故障演示、Mock 泄漏检查。

## 安全边界

I0 只验证同一事件的业务事实、角色视图和证据链；不得绕过 Core/Policy/Consent，浏览器
不得直连模型服务。视觉和 Agent 仍只能提供候选/建议，不能自动报警、给药或执行未授权
数据访问。

## 回滚
